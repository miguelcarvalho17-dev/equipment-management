> **Sandbox verification (2026-11-24):** verified in a Business Central sandbox by the project owner; no defects were reported. The detailed results are not recorded here, so statements below that say "not verified" or carry `TODO(verify)` predate this run.

## Purpose
A utilization figure for the equipment (GitHub issue #78). It shows how much of the equipment is assigned, as a percentage: total, assigned, available and in-maintenance equipment, and the utilization percentage (assigned divided by total equipment, times 100). The user can limit the figures with the request page filters on **Category Code** and **Location Code**. The report is read-only.

## What the report shows
One row with five figures, in this order:

| Column | Content |
|---|---|
| TotalEquipment | Equipment whose status is not Lost and not Disposed |
| AssignedEquipment | Equipment with status Assigned |
| AvailableEquipment | Equipment with status Available |
| InMaintenanceEquipment | Equipment with status In Maintenance |
| UtilizationPct | Assigned / Total * 100, rounded to two decimals. 0 when Total is 0 |

The column names are the dataset names. The Excel layout shows them as the headers of the Data sheet.

## Request page filters
The request page has one filter tab, **Equipment**, with two filter fields: **Category Code** and **Location Code**. Both use the standard filter fields of Business Central, so a filter can be a single value, a list or a range. Other fields can be added with **+ Filter**.

With no filter, all equipment is evaluated.

## Rules
- **Total excludes Lost and Disposed.** Both statuses are final and cannot be assigned, so they are not counted in Total. Statuses added by enum extensions are counted in Total.
- **Assigned, Available and In Maintenance** count the equipment with that status, within the request filters.
- **Utilization % = Assigned / Total * 100**, rounded to two decimals. It is 0 when Total is 0. No error is raised.
- **A user filter on Status** (added with **+ Filter**) combines with the rule (AND). Lost and Disposed are still never counted: a filter on Status = Lost or Disposed gives 0 in every figure.
- **Filters on the request page** are applied to the calculation. The filters on the list page the report is started from are not used.
- The report reads the current company only. It changes no data.

## Output
One Excel workbook. The data sheet has the five column headers in the first row and one row of figures. The platform also writes the filters the user chose into the workbook's hidden filter sheet (to be checked in sandbox check S3). The layout has no formatting, no totals and no chart yet. A designed layout is a later decision (phase 2).

## Permissions
- **EQM - Reader** has execute on the report, so Equipment Reader can run it. Equipment Manager and Equipment Administrator inherit it.
- **EQM - API Consumer** has no access to the report.
- The report reads equipment only. No employee, category or other table is read.

## Design decisions
- **Total excludes Lost and Disposed.** Both statuses can never be assigned again. Counting them would lower the utilization for good as equipment is written off. This is the reason the report total differs from the dashboard "Total Equipment" tile, which counts all statuses.
- **An In Maintenance figure is shown.** Without it, Total would not equal Assigned plus Available.
- **Two-decimal rounding**, as in other Business Central reports.
- **Category Code and Location Code** are the default filters. Every other field can be added with **+ Filter**.
- **One summary row.** A per-category breakdown is phase 2.
- **Rules in a codeunit, not in the report.** The counts and the percentage are internal procedures of codeunit 50107, so they can be tested without the report. The report only calls them.
- **Own filter group for the rule.** The rule filter is set in filter group 10, outside the groups the platform uses (0 to 7). A user filter on Status still applies, and the caller's record is not changed.
- **Count, not loop.** Each figure is one SQL count. No Commit.
- **Entry points:** the Tell Me search, the Report group of the Equipment List and the Reporting area of the Equipment Manager Role Center.
- **No cue tile.** A Utilization % tile on the dashboard or Role Center is phase 3, if requested. It would reuse the same calculation.

## Translations
New captions, ToolTips, the layout caption and summary, and the search terms are in `app/Translations/Equipment Management.g.xlf`, regenerated by the build. Never edit it by hand.

## Known limitations
- Total is not the sum of Assigned, Available and In Maintenance when an extension adds a status. The report counts such a status in Total only.
- The Excel output is a plain data row. It has no formatting, totals or charts.
- The report has one layout. There is no printable layout.
- There is no breakdown per category, location or employee, and no utilization over time.
- The figures are calculated when the report runs, not stored. Two runs at different times can differ.
- The request page filters are not pre-filled from the list page the report is started from.
- Platform behaviour when no equipment matches the filters is not tested automatically. It is a sandbox check (S3).
