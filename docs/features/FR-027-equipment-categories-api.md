# FR-027 Equipment Categories API

## Purpose
Read-only Business Central API v1.0 entity `categories` on table 50101 "EQM Equipment Category" (FR-002), so external systems can list categories and resolve the `categoryCode` values returned by `equipments` (FR-026) (GitHub issue #65). ## Endpoint
`/api/miguelCarvalho/equipment/v1.0/companies({companyId})/categories` and `.../categories({id})`, where `{id}` is the `id` (SystemId) field. Entity `category`, entity set `categories`, `ODataKeyFields = SystemId`.

## Fields
All read-only (page `Editable = false`).

| API field | Table field |
|---|---|
| `id` | SystemId |
| `code` | Code |
| `description` | Description |
| `active` | Active |
| `lastModifiedDateTime` | SystemModifiedAt |

## Behavior
- Returns **all** categories, active and inactive. Equipment can still reference an inactive category, so clients can resolve every `categoryCode`. Filter with `$filter=active eq true` for active ones only.
- GET only. The page sets `InsertAllowed`, `ModifyAllowed`, `DeleteAllowed` and `Editable` to false and `DataAccessIntent = ReadOnly`. POST, PATCH and DELETE are expected to be rejected; the HTTP status is **not verified** (V1). No page triggers or procedures. `Extensible = false`.
- Categories are maintained in the UI by administrators.
