# FR-052 Usage Analytics

## Purpose
Gives managers a view of how the equipment register is used over a period. One Excel report, **Usage Analytics**, shows four metrics: the most assigned categories, the maintenance trends, the growth of the equipment register and the number of active users. Each metric is one sheet of the workbook. The report calculates the figures from data the app already records (assignments, posted maintenance, equipment and the audit trail) when it runs. Nothing new is stored.

## Request page: the period
The request page has two fields: **Starting Date** and **Ending Date**.

- **Default:** the period is the 12 calendar months up to the work date. The starting date is the first day of the month 11 months before the work date. The ending date is the work date.
- **Both dates must be filled.** A blank date stops the report with an error. Nothing is shown.
- **The starting date must be on or before the ending date.** A reversed period stops the report with an error that shows both dates.
- **The period can be at most 120 calendar months.** A longer period stops the report with an error that shows the length and the maximum.
- The checks run before any figure is calculated. A failed check produces no output.
- The report reads the current company only.

## What the report shows
The workbook has four data sheets. Each sheet has the captions of its columns as headers. The table for each sheet also lists the dataset column names, for reference when you build a PivotTable or a macro.

### Most Assigned Categories (sheet MostAssignedCategories)
One row per category that has at least one assignment in the period.

| Column | Dataset name | Content |
|---|---|---|
| Rank | CategoryRank | The position in the list, 1 for the most assigned. Ties do not share a rank. |
| Category Code | CategoryCode | The code of the category. Blank for the row "Without category". |
| Category Description | CategoryDescription | The description of the category. "Without category" for the row without a category. |
| No. of Assignments | NoOfAssignments | The number of assignment entries in the period. |
| Share of Assignments % | AssignmentSharePct | The row's count as a share of all assignments in the period, rounded to 0.01. |

Rules:
- An assignment counts when its Assignment Date is in the period. Every status counts: active and closed entries are both counted.
- The category is the **current** category of the equipment. Assignment entries do not store a category. If equipment moves to another category, its past assignments count under the new category.
- Rows are sorted by the number of assignments, highest first. Categories with the same count are sorted by code. The "Without category" row comes before a category with the same count.
- **"Without category" is one row for two cases:** assignments of equipment that has no category, and assignments of equipment that no longer exists. Both are added to the same row, with a blank code.
- The share is calculated over all assignments in the period, including the "Without category" row.
- A period with no assignments gives no rows.

### Maintenance Trends (sheet MaintenanceTrends)
One row per calendar month of the period, including months with no maintenance.

| Column | Dataset name | Content |
|---|---|---|
| Period Start Date | TrendPeriodStart | The first day of the month. For the first month, the starting date of the period. |
| Period End Date | TrendPeriodEnd | The last day of the month. For the last month, the ending date of the period. |
| No. of Maintenances | NoOfMaintenances | The number of posted maintenance entries in the month. |
| Maintenance Cost | MaintenanceCost | The sum of the cost of those entries. |

Rules:
- Only **posted** maintenance counts, by its Maintenance Date. Open maintenance records are not counted.
- An entry with a cost of zero is counted.
- A month without posted maintenance shows 0 and a cost of 0.

### Equipment Growth (sheet EquipmentGrowth)
One row per calendar month of the period.

| Column | Dataset name | Content |
|---|---|---|
| Period Start Date | GrowthPeriodStart | As above. |
| Period End Date | GrowthPeriodEnd | As above. |
| New Equipment | NewEquipment | The number of equipment records created in the month. |
| Total Equipment | TotalEquipment | The number of equipment records created up to the end of the month. |

Rules:
- The creation date is the system creation time of the record (SystemCreatedAt), not the purchase date.
- All statuses count, including Lost and Disposed.
- Total Equipment counts the equipment that is in the register now. Equipment that was deleted is not in the register, so it is not counted in any month. For a past month, the total can therefore be lower than it was at that time.

### Active Users (sheet ActiveUsers)
One row per calendar month of the period.

| Column | Dataset name | Content |
|---|---|---|
| Period Start Date | UsersPeriodStart | As above. |
| Period End Date | UsersPeriodEnd | As above. |
| Active Users | ActiveUsersCount | The number of different users in the month. |

Rules:
- A user counts when the user has an audit entry (field "User ID", by "Logged At") or a posted maintenance (field "Posted By", by "Posted At") in the month. Blank user IDs are not counted.
- Each user is counted once per month.
- A user who is active in two months is counted in both months. The rows are not added up to a distinct count for the whole period.
- **No user ID is shown** in the output, in any column or sheet. Only counts are shown.
- Requests and approvals are not counted. They are planned for phase 2.

## Calculation notes
- The report calculates the figures every time it runs. Two runs at different times can give different results.
- The report writes nothing to the database, takes no locks and does not commit.
- The report uses the local month boundaries of the session that runs it on all four sheets. The results depend on that session's time zone. See the known limitations.

## Entry points and permissions
- **Tell Me:** search for "Usage Analytics".
- **Equipment List:** the action **Usage Analytics** in the Reporting area, promoted in the Report group.
- **Equipment Manager Role Center:** the action **Usage Analytics** in the Reporting area.
- **EQM - Reader** can run the report. EQM - Manager and EQM - Administrator inherit the permission.
- **EQM - API Consumer** has no access to the report or the query.
- The buffer table and the codeunit are temporary or internal. They need no table data permission.
- The report reads equipment, categories, assignments, maintenance history and the equipment audit trail. EQM - Reader has read permission on all of them. A custom role without read permission on the audit trail or the maintenance history gets a platform permission error when it runs the report.
- The report does not read employees or vendors.

## Design decisions
- **Calculated on demand, no stored snapshot.** Each metric already has a dated source. A snapshot table would need a job queue entry and install code.
- **One Excel report with four sheets,** as in FR-039 to FR-041.
- **Assignments are counted in the query.** The count runs in the database over the assignment entries of the period, so a large register does not need a loop in AL.
- **Monthly counts for trends and growth.** Each month is read with its own filter. This keeps the month boundaries the same as the local dates of the user.
- **Counts only for Active Users.** User IDs are not shown (personal data).
- **Current category for assignments.** Assignment entries do not store a category, and storing one would need a new field and an upgrade.

## Known limitations
- **Time zone of the session.** The month of each entry and the period limits follow the time zone of the session that runs the report. A session in another time zone, for example a job queue session, can count entries in different months. The check is UA-SB6 in `docs/TODO.md`.
- **Performance.** The assignment and audit tables have no index on the dates. A run over a large register can take several seconds. The check is UA-SB5.
- **Total Equipment** does not include equipment that has been deleted.
- **Active Users** is not a distinct count for the whole period. The sum of the monthly values is not the number of users in the period.
- **Category** is the current one. After equipment moves to another category, its past assignments count under the new category.
- **"Without category"** also holds assignments of equipment that no longer exists. The report cannot tell these apart.
- **Excel output** is a plain data table. It has no formatting, totals, PivotTables or charts.
- **Empty period:** what the platform shows for a period with no data is a sandbox check.
- No dashboard tile, chart, feature switch or drill-down.
