# Equipment Management user guide (AppSource end-user help)

This article points to the user guide for Equipment Management. The guide covers setup, daily work, reports, integration and security in one place. It is for end users, managers, administrators and integrators. The design is described in `docs/features/FR-059-user-documentation.md`.

The guide applies to Equipment Management 29.0.0.0, which is not released yet. Its steps are not verified in a Business Central sandbox. TODO(verify): check the menu names and Tell Me categories against your version of Business Central.

## Where the guide is
The guide is in the `docs/user-guide/` folder of the repository. Start with the overview page.

## How the guide relates to the feature articles
The guide describes the app as a whole. Each functional page ends with a **Related** list that links the feature articles it was built from. The feature articles keep the details of each change. If the guide and a feature article disagree, follow the guide and the app.

## Release notes
Equipment Management has a single end-user guide. It covers setup, each functional area, integration, the API, reports, security and the release notes. The guide adds no change to the app.
