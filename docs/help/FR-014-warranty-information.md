# Warranty information (AppSource end-user help)

Record the warranty of each piece of equipment, so you can see whether a repair is still covered before you register maintenance. Warranty information is optional.

## Before you start: permissions
**Equipment Manager** and **Administrator** can enter, change and clear warranty information. **Equipment Reader** can see it and filter on it, but cannot change it.

## Enter the warranty
1. Open the equipment on the **Equipment Card**.
2. In the **Warranty** section (below **Purchase**), fill in the fields you know:
   - **Warranty Start Date**: the date the warranty starts.
   - **Warranty End Date**: the date the warranty ends.
   - **Warranty Provider**: the company that provides the warranty, for example the manufacturer, the vendor or a service company. Free text.
   - **Warranty Reference No.**: the contract, certificate or registration number from the provider.

When the section is collapsed, it shows **Warranty End Date** and **Warranty Provider**.

## Rules
- All fields are optional. Leave a date blank when there is no warranty or you do not know the date. You can fill in just one date.
- When you fill in both dates, the end date must be **later** than the start date. The same day is not accepted. If not, you get an error and the date is not accepted.
- To move a warranty to a later period, change the end date first and then the start date. If you change the start date first to a date after the current end date, you get the error. Change the other date, or clear it.
- Dates may be in the past or in the future. Warranty fields can also be changed on lost and disposed equipment.

## On the Equipment list
The four warranty fields are hidden by default. Use the column chooser (personalization) to show them. To find equipment whose warranty ends soon, filter **Warranty End Date**, for example to a period.

## Release notes
You can now record the warranty of each piece of equipment: start date, end date, provider and reference number. The fields are in the new Warranty section of the Equipment Card and can be shown as columns on the Equipment list, for example to filter on the warranty end date. All fields are optional. When you fill in both dates, the end date must be later than the start date.
