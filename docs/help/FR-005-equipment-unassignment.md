# Return equipment (AppSource end-user help)

When an employee gives equipment back, return it. The employee is removed, the status becomes **Available**, and the
assignment is closed. The assignment stays in the history, so you can still see who had the equipment and when.

## Before you start: permissions
- **Equipment Manager** to return equipment.
- **Equipment Reader** (included in Manager) as well to use **Return Equipment** on the employee card.

## Return equipment from the equipment card
1. Open the card of equipment with the status **Assigned**.
2. Choose **Return**. The action is available only for assigned equipment.
3. Confirm the question. The status changes to **Available**, the employee is cleared, and the assignment is closed with your work date and your user name.

If you choose **No**, nothing changes.

## Return equipment from the employee card
1. Open the employee card and choose **Return Equipment**.
2. If the employee has no assigned equipment, a message tells you so.
3. Otherwise a list shows only the equipment assigned to that employee. Select one and choose OK.
4. Confirm the question. The equipment is returned as described above.

If the equipment was returned by someone else in the meantime, you get a message that it is no longer assigned to the employee.

## Good to know
- Assigned equipment becomes **Available** only through **Return**. If you choose **Available** in the **Status** field of assigned equipment, you get a message to use the Return action.
- You can still change assigned equipment to **In Maintenance**, **Lost** or **Disposed** in the **Status** field; the assignment is closed then too.
- Returned equipment can be assigned again with **Assign to Employee**. The old assignment stays closed and a new one is created.
- Closed assignments are never deleted. Equipment that has been assigned at least once can no longer be deleted; set it to **Disposed** instead. See the FR-006 help.
- Use **Assignments** on the equipment card or **Navigate > Equipment Assignments** on the employee card to see the history.

## Release notes
Equipment can now be returned from the equipment card or the employee card. A return sets the status to Available and closes the assignment, which stays in the history. Assigned equipment can no longer be changed to Available through the Status field; use Return. The action formerly called Unassign is now called Return.
